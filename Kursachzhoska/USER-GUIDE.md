# Kursachzhoska - Event Management System

## 📥 Установка

### Способ 1: Через установщик (Рекомендуется)

1. Запустите файл `Kursachzhoska-Setup.exe`
2. Следуйте инструкциям установщика
3. Выберите папку для установки (или оставьте по умолчанию)
4. Приложение установится и запустится автоматически
5. Ярлык появится на рабочем столе и в меню Пуск

### Способ 2: Портативная версия (без установки)

1. Распакуйте архив `Kursachzhoska-Portable.zip`
2. Откройте папку
3. Запустите файл `Kursachzhoska.exe`
4. Готово! Можно использовать

## 🚀 Запуск приложения

- **После установки:** Двойной клик по ярлыку на рабочем столе
- **Портативная версия:** Двойной клик по `Kursachzhoska.exe`

## 📋 Системные требования

- **Операционная система:** Windows 10 или Windows 11 (64-bit)
- **Оперативная память:** Минимум 2 GB
- **Свободное место:** ~200 MB
- **Не требуется:** Установка .NET Framework или других компонентов

## ⚙️ Функции приложения

### Главные возможности:
- 📅 **Просмотр каталога событий** - все доступные мероприятия
- ❤️ **Избранное** - сохраняйте интересные события
- 📝 **Мои события** - управление созданными событиями
- 📜 **История** - просмотр посещенных мероприятий
- 🔔 **Уведомления** - будьте в курсе важных событий
- 👤 **Профиль** - управление личными данными

### Для организаторов:
- ➕ **Создание событий** - публикация новых мероприятий
- ✏️ **Редактирование** - изменение информации о событиях
- 👥 **Список гостей** - управление участниками
- ⭐ **Отзывы** - просмотр и управление отзывами

## 🎨 Интерфейс

Приложение имеет современный и интуитивный интерфейс:
- Боковая панель навигации слева
- Основная область контента справа
- Кастомные компоненты (календарь, иконки)
- Плавные анимации и переходы

## 🔐 Вход в систему

При первом запуске:
1. Используйте демо-аккаунт для тестирования
2. Или зарегистрируйте новый аккаунт
3. Войдите и начните использовать

## ❓ Часто задаваемые вопросы

### Нужно ли устанавливать .NET?
**Нет!** Приложение содержит все необходимые компоненты.

### Можно ли запускать с флешки?
**Да!** Используйте портативную версию.

### Как обновить приложение?
Скачайте новую версию и установите поверх старой (настройки сохранятся).

### Приложение не запускается
Проверьте:
- Версия Windows (требуется 10/11)
- Достаточно места на диске
- Антивирус не блокирует
- Файлы не повреждены при скачивании

### Как удалить приложение?

**Установленная версия:**
- Панель управления → Программы и компоненты
- Найдите "Kursachzhoska" → Удалить

**Портативная версия:**
- Просто удалите папку с приложением

## 🛡️ Безопасность

- Не собирает личные данные
- Не устанавливает дополнительное ПО
