# Инструкция по созданию установщика и развертыванию

## 📦 Быстрый старт

### Вариант 1: Установщик с Inno Setup (Рекомендуется)

1. **Установите Inno Setup** (если еще не установлен):
   - Скачайте с https://jrsoftware.org/isinfo.php
   - Установите версию 6.0 или выше

2. **Запустите сборку**:
   ```bash
   publish.bat
   setup-builder.bat
   ```

3. **Результат**:
   - Установщик будет создан в папке `installer-output\`
   - Файл: `Kursachzhoska-Setup.exe`
   - Поделитесь этим файлом с пользователями!

### Вариант 2: Портативная версия (без установки)

1. **Запустите**:
   ```bash
   publish.bat
   create-portable.bat
   ```

2. **Результат**:
   - ZIP архив: `Kursachzhoska-Portable.zip`
   - Папка: `Kursachzhoska-Portable\`
   - Пользователи просто распаковывают и запускают

## 🔧 Подробные инструкции

### Шаг 1: Публикация приложения

Запустите `publish.bat` - это создаст самодостаточную версию приложения со всеми зависимостями.

**Что делает скрипт:**
- Компилирует приложение в Release режиме
- Создает self-contained версию (не требует установленного .NET)
- Объединяет все в один исполняемый файл
- Оптимизирует для быстрого запуска

**Результат:** Папка `publish\` с готовым приложением

### Шаг 2А: Создание установщика (Inno Setup)

Запустите `setup-builder.bat`

**Возможности установщика:**
- ✅ Установка в Program Files
- ✅ Создание ярлыка на рабочем столе
- ✅ Добавление в меню Пуск
- ✅ Удобная деинсталляция
- ✅ Автозапуск после установки
- ✅ Поддержка русского языка

**Результат:** `installer-output\Kursachzhoska-Setup.exe`

### Шаг 2Б: Создание портативной версии

Запустите `create-portable.bat`

**Преимущества:**
- ✅ Не требует установки
- ✅ Можно запускать с USB
- ✅ Легко делиться через облако
- ✅ Не требует прав администратора

**Результат:** 
- `Kursachzhoska-Portable.zip` - для распространения
- `Kursachzhoska-Portable\` - папка с приложением

## ⚙️ Настройка установщика

Отредактируйте `installer-script.iss` для изменения:

```iss
#define MyAppName "Kursachzhoska"           ; Название приложения
#define MyAppVersion "1.0.0"                ; Версия
#define MyAppPublisher "Event Management"   ; Издатель
```

**Дополнительные настройки:**
- Добавить иконку: установите `SetupIconFile=path\to\icon.ico`
- Изменить папку установки: измените `DefaultDirName`
- Добавить лицензию: установите `LicenseFile=license.txt`

## 🐛 Решение проблем

### "Inno Setup not found"
**Решение:** 
- Установите Inno Setup с https://jrsoftware.org/isinfo.php
- Или используйте портативную версию: `create-portable.bat`

### "Published files not found"
**Решение:**
- Сначала запустите `publish.bat`
- Дождитесь завершения публикации

### "dotnet not found"
**Решение:**
- Установите .NET SDK 8.0: https://dotnet.microsoft.com/download

### Приложение не запускается у пользователя
**Проверьте:**
- Windows 10/11 x64
- Достаточно места на диске
- Отключен антивирус (может блокировать)
- Скачан полностью (не поврежден)

## 📊 Размеры файлов

Примерные размеры:
- **Исходный код:** ~5 MB
- **Опубликованное приложение:** ~150-200 MB (включает весь .NET runtime)
- **Установщик (сжатый):** ~80-100 MB
- **ZIP портативная версия:** ~80-100 MB

*Размер большой, потому что включает весь .NET runtime для работы без установки .NET*

   ```bash

   setup-builder.bat
   ```

3. Новый установщик готов!
