================================================================================
  iCelebrate — инструкция для запуска (Windows)
================================================================================

НУЖНО ЗАРАНЕЕ:
  Docker Desktop — https://www.docker.com/products/docker-desktop/
  После установки запусти Docker Desktop и дождись статуса "Engine running".

================================================================================
  БЫСТРЫЙ СТАРТ
================================================================================

1. Распакуй этот архив в любую папку, например:
   C:\ICelebrate

2. Открой PowerShell в этой папке:
   - Shift + правая кнопка мыши по папке → "Открыть окно PowerShell здесь"
   - или: Win+X → Терминал, затем:
     cd C:\ICelebrate

3. Запусти сервер (первый раз долго, 5–20 минут):

   docker compose up --build

   НЕ ЗАКРЫВАЙ это окно, пока пользуешься приложением!

4. Запуск приложения — выбери один вариант:

   ВЕБ-ВЕРСИЯ:
   Открой браузер → http://localhost:3000

   ДЕСКТОП-ВЕРСИЯ:
   Открой папку desktop-release и запусти iCelebrate.exe
   (двойной клик)

5. Зарегистрируйся на сайте или в десктопе.
   В профиле можно стать организатором и создавать мероприятия.

================================================================================
  ПОВТОРНЫЙ ЗАПУСК (на следующий день)
================================================================================

1. Запусти Docker Desktop
2. PowerShell в папке проекта:
   docker compose up
3. Браузер: http://localhost:3000
   или запусти desktop-release\iCelebrate.exe

================================================================================
  ОСТАНОВКА
================================================================================

В окне PowerShell с docker compose нажми Ctrl+C, затем:
   docker compose down

================================================================================
  ЕСЛИ НЕ РАБОТАЕТ
================================================================================

- Docker Desktop запущен? (кит в трее, Engine running)
- Окно с docker compose up не закрыто?
- Подожди 1–2 минуты после старта
- Проверь в браузере: http://localhost:8000/api/events/
  (должен открыться текст JSON)
- Десктоп не работает без запущенного Docker!
