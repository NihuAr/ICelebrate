# iCelebrate — Подробный гайд по запуску через Docker (Windows)

Этот гайд для человека, который **уже установил Docker Desktop** и получил проект (ссылку на GitHub или zip-архив).

После выполнения всех шагов приложение откроется в браузере по адресу:

**http://localhost:3000**

---

## Что будет запущено

Docker поднимет сразу 3 части проекта:

| Сервис   | Что это            | Адрес                    |
|----------|--------------------|--------------------------|
| frontend | Веб-интерфейс      | http://localhost:3000    |
| backend  | API (Django)       | http://localhost:8000    |
| db       | База PostgreSQL    | только внутри Docker     |

Тебе для демо нужен в основном **http://localhost:3000**.

---

## Шаг 0. Проверь, что Docker действительно работает

1. Открой **Docker Desktop** (иконка кита в трее Windows, возле часов).
2. Дождись, пока внизу слева будет написано **Engine running** (зелёный индикатор).
3. Если Docker просит перезагрузить ПК после установки — **перезагрузи** и только потом продолжай.

### Быстрая проверка через терминал

1. Нажми `Win + X` → выбери **Терминал** или **PowerShell**.
2. Введи команду:

```powershell
docker --version
```

Должно появиться что-то вроде:

```
Docker version 27.x.x, build ...
```

3. Проверь, что Docker отвечает:

```powershell
docker ps
```

Если ошибок нет (даже пустой список — это нормально) — всё готово.

**Если пишет, что `docker` не найден:**
- закрой и открой терминал заново;
- убедись, что Docker Desktop запущен;
- перезагрузи компьютер.

## Шаг 1. Скачай проект

### Вариант А — через Git (рекомендуется)

1. Открой **PowerShell** или **Терминал**.
2. Перейди в папку, куда хочешь положить проект. Например, на Рабочий стол:

```powershell
cd $env:USERPROFILE\Desktop
```

3. Склонируй репозиторий:

```powershell
git clone https://github.com/NihuAr/ICelebrate.git
```

4. Зайди в папку проекта:

```powershell
cd ICelebrate
```

5. Убедись, что ты в правильной папке — там должен быть файл `docker-compose.yml`:

```powershell
dir docker-compose.yml
```

Если файл найден — отлично.

### Вариант Б — через zip-архив

1. Распакуй архив, например в `C:\Users\ТвоёИмя\Desktop\ICelebrate`
2. Открой PowerShell.
3. Перейди в распакованную папку:

```powershell
cd C:\Users\ТвоёИмя\Desktop\ICelebrate
```

4. Проверь наличие `docker-compose.yml`:

```powershell
dir docker-compose.yml
```

## Шаг 2. Первый запуск проекта

### 2.1. Запусти сборку и старт всех контейнеров

В папке проекта (где лежит `docker-compose.yml`) выполни:

```powershell
docker compose up --build
```

> Если команда не работает, попробуй старый вариант:
> ```powershell
> docker-compose up --build
> ```

### 2.2. Что будет происходить

- Docker скачает образы (PostgreSQL, Python, Node.js, nginx) — **первый раз это долго: 5–20 минут**.
- Соберётся backend и frontend.
- Выполнятся миграции базы данных.
- В терминале побегут логи — **это нормально, не закрывай окно**.

### 2.3. Как понять, что всё готово

Жди, пока в логах появится что-то похожее на:

```
backend-1   | Booting worker with pid: ...
frontend-1  | ... start worker processes
```

И **не будет новых красных ошибок**.

Пока терминал с `docker compose up` открыт — проект работает.

### 2.4. Открой сайт в браузере

1. Открой **Chrome**, **Edge** или **Firefox**.
2. В адресной строке введи:

```
http://localhost:3000
```

3. Должна открыться главная страница **iCelebrate**.

**Не закрывай терминал**, в котором запущен `docker compose up` — иначе сайт остановится.

## Шаг 3. Создай пользователя для входа

Сайт уже работает, но для демо нужен аккаунт.

### 3.1. Открой второй терминал

- Оставь первый терминал с логами **открытым**.
- Открой **новое** окно PowerShell (`Win + X` → Терминал).

### 3.2. Перейди в папку проекта

```powershell
cd $env:USERPROFILE\Desktop\ICelebrate
```

(или твой путь к папке)

### 3.3. Создай суперпользователя

```powershell
docker compose exec backend python manage.py createsuperuser
```

Тебя спросят:

| Вопрос            | Что ввести (пример для демо) |
|-------------------|------------------------------|
| Username          | `demo`                       |
| Email               | можно просто Enter (пусто)   |
| Password            | `demo123`                    |
| Password (again)    | `demo123`                    |

> При вводе пароля символы **не отображаются** — это нормально, просто печатай и нажми Enter.

### 3.4. Войди на сайт

1. Открой http://localhost:3000
2. Нажми **Войти** / **Login**
3. Введи:
   - Логин: `demo`
   - Пароль: `demo123`

Если вход прошёл — всё настроено правильно.

## Шаг 4. Добавь тестовые данные для показа преподавателю

Пустой каталог на защите выглядит плохо. Добавь несколько мероприятий через админку.

### 4.1. Открой админ-панель

В браузере:

```
http://localhost:8000/admin/
```

Войди теми же данными: `demo` / `demo123`

### 4.2. Создай мероприятия

1. Найди раздел **Events** (или **Мероприятия** / **События**).
2. Нажми **Add** / **Добавить**.
3. Заполни поля (название, описание, дата, место и т.д.).
4. Сохрани.
5. Создай **минимум 3–5 мероприятий** с разными названиями.

### 4.3. Проверь на основном сайте

1. Открой http://localhost:3000
2. Зайди в каталог / список мероприятий.
3. Убедись, что созданные события видны.

### 4.4. Что показать преподавателю (чек-лист)

- [ ] Главная страница
- [ ] Каталог мероприятий
- [ ] Карточка одного мероприятия
- [ ] Регистрация / вход
- [ ] Профиль пользователя
- [ ] (если есть) избранное, заявки, отзывы

Пройдись по этому списку **за день до защиты**, чтобы не искать баги в последний момент.

## Шаг 5. Как показывать преподавателю

1. За **5–10 минут** до показа открой терминал и запусти:

```powershell
cd путь\к\ICelebrate
docker compose up
```

(второй и дальнейшие разы `--build` обычно не нужен, если код не менялся)

2. Дождись запуска.
3. Открой http://localhost:3000
4. Войди под `demo` / `demo123`
5. Показывай на экране ноутбука.

**Важно:** преподаватель не сможет открыть сайт со своего телефона/дома, если только у него нет доступа к твоему ноутбуку. Это локальный запуск на твоём компьютере.

## Шаг 6. Остановка и повторный запуск

### Остановить проект

В терминале, где запущен `docker compose up`, нажми:

```
Ctrl + C
```

Потом (необязательно, но аккуратно):

```powershell
docker compose down
```

### Запустить снова (на следующий день)

```powershell
cd путь\к\ICelebrate
docker compose up
```

Данные в базе **сохранятся** между перезапусками (если не удалять Docker volumes).

## Частые проблемы и решения

### «Порт уже занят» / `port is already allocated`

Значит порт 3000 или 8000 уже кем-то занят.

**Решение 1:** останови другие контейнеры:

```powershell
docker compose down
```

**Решение 2:** закрой другие программы, которые могли занять порт, и попробуй снова.

**Решение 3:** перезагрузи компьютер и запусти только этот проект.

---

### `http://localhost:3000` не открывается

Проверь по порядку:

1. Docker Desktop запущен? (Engine running)
2. Терминал с `docker compose up` всё ещё открыт?
3. В логах нет красных ошибок?
4. Попробуй http://127.0.0.1:3000
5. Попробуй другой браузер
6. Подожди ещё 1–2 минуты после старта

Проверь API напрямую:

```
http://localhost:8000/api/events/
```

Если здесь открывается JSON — backend работает, проблема во frontend.

---

### Ошибка при `docker compose up --build`

1. Скопируй **последние 20–30 строк** из терминала.
2. Отправь тому, кто дал проект.
3. Попробуй пересобрать с нуля:

```powershell
docker compose down
docker compose up --build
```

Если не помогло — полная пересборка:

```powershell
docker compose down -v
docker compose up --build
```

> **Внимание:** `down -v` удалит данные в базе (созданных пользователей и мероприятий). После этого нужно снова сделать `createsuperuser` и добавить события.

---

### `createsuperuser` пишет ошибку

Убедись, что:
1. Проект уже запущен (`docker compose up` работает в другом окне).
2. Ты в папке с `docker-compose.yml`.
3. Команда именно такая:

```powershell
docker compose exec backend python manage.py createsuperuser
```

---

### Вход не работает / «Неверный логин или пароль»

1. Создай пользователя заново или другого пользователя через `createsuperuser`.
2. Либо зарегистрируйся через кнопку **Регистрация** на сайте http://localhost:3000

---

### Docker Desktop очень медленный

- Закрой лишние программы.
- В Docker Desktop → Settings → Resources можно выделить больше RAM (например 4 GB), если позволяет ПК.
- Первый запуск всегда самый долгий.

---

### Ошибка WSL / «Docker Desktop requires WSL 2»

На Windows Docker часто требует WSL2:

1. Docker Desktop покажет кнопку **Install WSL** или ссылку на инструкцию — следуй ей.
2. Перезагрузи ПК.
3. Снова открой Docker Desktop.

## Шпаргалка команд (всё в одном месте)

```powershell
# Перейти в папку проекта
cd путь\к\ICelebrate

# Первый запуск (долго)
docker compose up --build

# Обычный запуск
docker compose up

# Создать пользователя (в отдельном терминале, пока проект работает)
docker compose exec backend python manage.py createsuperuser

# Остановить
# Ctrl+C в терминале с логами, затем:
docker compose down
```
